Règles de confidentialité — persovideo

Dernière mise à jour : 13 novembre 2026

Français

  • Usage : persovideo est un outil personnel qui publie des vidéos générées automatiquement sur les comptes (YouTube, TikTok, Instagram) de son seul propriétaire.
  • Données utilisées : uniquement les jetons d'autorisation fournis par le propriétaire, nécessaires à la mise en ligne des vidéos. Ils sont stockés de façon chiffrée (secrets GitHub Actions) et ne sont jamais partagés.
  • Données de tiers : aucune. L'outil ne lit, ne collecte, ne vend ni ne partage aucune donnée d'autres utilisateurs.
  • Services Google : l'utilisation des données reçues des API Google respecte les règles relatives aux données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée. L'accès peut être révoqué à tout moment sur myaccount.google.com/permissions.
  • Contact : via la page GitHub du projet.

English

  • Purpose: persovideo is a personal tool that uploads automatically generated videos to its owner's own accounts (YouTube, TikTok, Instagram).
  • Data used: only the authorization tokens provided by the owner, required to upload the videos. They are stored encrypted (GitHub Actions secrets) and never shared.
  • Third-party data: none. The tool does not read, collect, sell or share any other user's data.
  • Google services: use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
  • Contact: via the project's GitHub page.
