Privacy Policy — persovideo

Last updated: November 13, 2026 · Version française plus bas

1. YouTube API Services

persovideo uses YouTube API Services (YouTube Data API v3) to upload videos to its owner's own YouTube channel. By using persovideo, you agree to be bound by the YouTube Terms of Service. YouTube and Google's handling of data is governed by the Google Privacy Policy (http://www.google.com/policies/privacy).

2. Information accessed, collected and used

  • persovideo only uses the OAuth authorization granted by its owner with the youtube.upload scope, to upload videos it generated itself.
  • It does not read, collect or use any other YouTube data (no comments, analytics, subscribers, viewing history or personal information).
  • It has no other users and collects no data from third parties.

3. Storage and sharing

  • The only stored information is the owner's OAuth credentials (client ID, client secret, refresh token), stored encrypted as GitHub Actions secrets.
  • No YouTube API data is stored. No information is sold, shared with or disclosed to third parties.
  • persovideo uses no cookies and no analytics or advertising trackers.

4. Revocation and deletion

  • Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions.
  • When access is revoked, or upon request, the stored OAuth credentials are deleted (removed from GitHub secrets) within 7 days. Since no YouTube API data is stored, there is no other data to delete.

5. Contact

Questions or deletion requests: github.com/gwenaelbrct/persovideo/issues.
